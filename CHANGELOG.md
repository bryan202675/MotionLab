# Changelog

Notable changes to MotionLab are recorded here.

## 0.2.0 — Unreleased

- Add 14 original experiment controls, timing references, and preview utilities.
- Expand component pages, previews, playground examples, and registry payloads to 38 items.
- Respect reduced-motion preferences in the new animated controls.

## 0.1.0 — Unreleased

- Create the pnpm monorepo with a Next.js documentation and catalog site.
- Add 24 original React motion components and a shadcn-compatible source registry.
- Add component search, API pages, documentation, a prop playground, themes, and showcase scenes.
- Add strict type checking, unit and browser tests, and GitHub Actions CI.
