# Security policy

## Reporting a vulnerability

Please do not report security issues in public issues. Use GitHub's private vulnerability reporting for this repository after it is published. If private reporting is unavailable, contact the repository owner privately through GitHub.

Include the affected version or commit, the impact, steps to reproduce, and any suggested mitigation. Do not include secrets or personal data in reports.

## Supported versions

The project has not published a release yet. Security fixes will target the current default branch until versioned releases are available.
