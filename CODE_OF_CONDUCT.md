# Contributor Covenant Code of Conduct

## Our pledge

We are committed to a welcoming, respectful, and harassment-free community for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our standards

Examples of behavior that contributes to a positive environment include being considerate, giving and accepting constructive feedback, acknowledging others' contributions, and focusing on what is best for the community.

Unacceptable behavior includes harassment, discriminatory language, personal attacks, publishing private information without permission, and other conduct that would be inappropriate in a professional setting.

## Scope and enforcement

This code applies in project spaces and when someone is representing the project publicly. Project maintainers may remove content or participation that violates it. Report concerns privately to the contact listed in the GitHub repository's security advisories or maintainers section. If no private contact is configured yet, use GitHub's private vulnerability reporting for security issues and contact a repository owner for conduct concerns.
