# Project context

## Product

MotionLab is an English-language, MIT-licensed React animation and interaction component library. Its accompanying Next.js App Router site provides a catalog, component references, a prop playground, documentation, and visual showcase.

## Stack

- pnpm workspaces
- Next.js App Router, React, and strict TypeScript
- Motion for React and Lucide React
- Tailwind CSS 4 plus custom CSS for the editorial visual identity
- Vitest, React Testing Library, Playwright, ESLint, and shadcn registry schemas

## Design

Contemporary digital brutalism with warm paper, ink, acid green, electric violet, and signal orange. Preserve legibility, keyboard access, responsive behavior, and reduced-motion support.

## Distribution status

The shadcn-compatible registry is generated locally. The repository has not been published to GitHub and the documentation site has not been deployed. The GitHub shorthand and production URLs become usable after those external steps.
